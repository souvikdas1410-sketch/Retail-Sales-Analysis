# Retail Sales Analysis Using Python and Power BI

## Project Overview
This project focuses on analyzing retail sales data to identify sales trends, product performance, and seasonal patterns using Python and Microsoft Power BI.

The objective is to clean and prepare the dataset, perform exploratory data analysis, and present meaningful insights through data visualization and an interactive dashboard.

## Tools and Technologies
- **Python:** Data analysis and preprocessing
- **Pandas:** Data cleaning and manipulation
- **Jupyter Notebook:** Python development and analysis
- **Microsoft Power BI:** Dashboard creation and data visualization

## Dataset Description
The dataset contains retail sales information, including:
- Year and Month
- Supplier
- Item Code
- Item Description
- Item Type
- Retail Sales
- Retail Transfers
- Warehouse Sales

## Project Workflow
1. **Data Inspection:** Examined the dataset structure and checked for missing values.
2. **Data Cleaning:** Handled missing values and prepared the data for analysis.
3. **Exploratory Data Analysis:** Used Python and Pandas to examine retail sales data.
4. **Data Preparation:** Exported the cleaned dataset for use in Power BI.
5. **Dashboard Development:** Created visualizations to explore retail sales performance and trends.

## Key Objectives
- Analyze sales patterns over time.
- Examine product and item-type performance.
- Explore retail sales, transfers, and warehouse sales.
- Present business information through visualizations and dashboard reporting.

## Project Files
- **Jupyter Notebook:** Python code and data preparation.
- **Power BI Dashboard:** Interactive dashboard for visual analysis.
- **Cleaned Dataset:** Processed dataset used for dashboard development, where sharing is permitted.

## Skills Demonstrated
Python, Pandas, Data Cleaning, Exploratory Data Analysis (EDA), Data Visualization, Microsoft Power BI, and Business Intelligence.

## Conclusion
This project demonstrates the use of Python and Power BI to prepare, analyze, and visualize retail sales data for business reporting and decision-making.
